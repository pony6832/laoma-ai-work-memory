# CODEX HANDOFF

工作結束前：
1. 執行必要測試並記錄結果。
2. 檢查 `git diff`，確認沒有密碼、Token、Cookie、私鑰、個資或公司機密。
3. 在專案的 `AI_WORKLOG.md` 追加本次紀錄。
4. 更新專案的 `NEXT_ACTIONS.md`。
5. 如本專案是目前主要工作，更新根目錄 `CURRENT_STATUS.md`。
6. 使用清楚的 Commit message 提交並 Push。

交接摘要固定格式：
- DEVICE：
- PROJECT：
- COMPLETED：
- TEST RESULT：
- FILES CHANGED：
- OPEN PROBLEMS：
- EXACT NEXT STEP：
- COMMIT SHA／PR：
